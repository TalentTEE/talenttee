## 크리티컬 패스

```
성훈 DB(Day1) → 준하 이력서(Day2) → 준하 매칭(Day3) → 승연 협상(Day3) → 승연 온체인(Day4) → 현정 연결(Day4)
```

**가장 위험한 구간**: 성훈 Day 1 오전이 지연되면 전체가 밀림. 오전 중 스키마 + 타입 PR 필수.

**전략**: 핵심 구현 2일(4/12-13)로 압축, 통합/검증/고도화에 3일(4/14-16) 투자. 기능 완성도보다 E2E 데모 완주에 집중.
