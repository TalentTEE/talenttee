01

Problem & Solution

기존 채용 시장의 한계를 AI와 블록체인으로 해결합니다

기존 채용 시장의 문제

  • 이력서 작성에 많은 시간과 노력이 필요
  • 구직자의 실제 역량이 이력서에 제대로 반영되지 않음
  • 수동 매칭으로 인한 비효율적 채용 프로세스
  • 연봉 협상에서 정보 비대칭 발생
  • 채용 계약의 불투명한 이행 과정
  • 지불 보증 장치 부재로 인한 신뢰 문제

TalentTee의 솔루션

  • GitHub/Slack 등 실제 데이터 기반 AI 이력서 자동 생성
  • 코드 활동, 커뮤니케이션 패턴에서 역량 객관적 분석
  • ANN + LLM 리랭킹으로 정밀한 자동 매칭
  • AI 에이전트가 양측의 이해를 대변하며 공정 협상
  • SHA-256 해시 + NEAR 블록체인으로 합의 무결성 보장
  • 스마트 컨트랙트 에스크로로 지불 보증

User Flow

구직자와 고용주의 여정

NEAR WALLET Sign Up / Login
JOB SEEKER
  1. Connect Data Sources
    GitHub · Slack · Discord · Gov24
  2. AI Resume Generation
    스킬 추출 · 시장 가치 분석 · 벡터 임베딩
  3. Enable Job Seeking
    자동 매칭 파이프라인 시작 · 6h 주기
  4. Review AI Matches
    매칭 점수 · 직무 상세 · 동의/거절
EMPLOYER
  1. Create Job with AI Chat
    AI 어시스턴트와 대화형 채용공고 작성
  2. Publish Job Posting
    게시 → AI 임베딩 → 자동 매칭 탐색
  3. Deposit Escrow
    NEAR 토큰 에스크로 예치 · 지불 보증
  4. Review Candidates
    AI 매칭 인재 검토 · 프로필 확인
양측 매칭 동의
  1. AI Autonomous Negotiation
    Seeker Agent vs Employer Agent · 암호화 다라운드 · 최대 5회
  2. Agreement & Approval
    양측 최종 합의 검토 · SHA-256 해시 · 쌍방 서명
  3. Blockchain Settlement
    NEAR 온체인 기록 · 에스크로 자동 정산
