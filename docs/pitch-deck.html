01

채용 시장은 망가져 있습니다

기존 채용 파이프라인은 마찰, 편향, 신뢰 부족으로 가득합니다.

이력서의 한계

이력서는 실제 역량을 반영하지 못합니다. 자기 보고식 스킬은 진실을 놓칩니다. 구직자는 고용주가 검증할 수 없는 내러티브를 작성하는 데 수 시간을 씁니다.

협상의 비대칭

정보 불균형이 양측 모두에게 불공정한 연봉 결과를 만듭니다. 고용주는 시장 데이터를 가지고, 구직자는 맹목적으로 협상합니다.

신뢰의 부재

지불 보증 없음. 불투명한 프로세스. 검증 가능한 합의 없음. 거래가 무산되면 기록도 구제책도 없습니다.

데이터 기반 이력서부터 자율 협상, 온체인 정산까지 — 하나의 매끄러운 파이프라인.

02

03

블록체인 에스크로

NEAR 스마트 컨트랙트 에스크로가 지불을 보증합니다. 합의 내용을 해시하여 온체인에 기록합니다. 신뢰가 프로토콜에 내장됩니다.

NEAR 생태계 완전 통합

AI 추론부터 온체인 정산까지 — NEAR 생태계 전반을 깊이 통합했습니다.

AI INFERENCE

NEAR AI Cloud

Qwen 3.5-122B 추론 및 협상용. Qwen 3-Embed-0.6B 1536차원 벡터 임베딩. OpenAI 호환 API로 모든 AI 기능 구동.

AUTHENTICATION

NEAR Protocol

NEP-413 서명 기반 인증. 비밀번호 없이, 이메일 인증 없이. 지갑 네이티브 로그인. NEAR 계정이 곧 신원입니다.

SMART CONTRACTS

Rust 컨트랙트

Escrow: deposit, pay_for_profile, withdraw. Agreement: store_agreement + SHA-256 해시 검증. 테스트넷 배포 완료.

DELEGATION

FunctionCall Access Keys

제한된 허용량의 서버 에이전트 키로 자동화된 온체인 트랜잭션. 전체 계정 접근 노출 없이 진정한 위임. 제로트러스트, 지출 상한.

06

기술적 하이라이트

TalentTee를 가능하게 한 기술 혁신.

01

하이브리드 AI 매칭

pgvector 코사인 유사도 기반 ANN 벡터 검색으로 후보를 빠르게 탐색. LLM 리랭킹으로 의미론적 적합성을 정밀 평가. 속도와 정확도의 2단계 파이프라인.

02

암호화 협상

Ed25519 키 교환으로 HKDF 세션 키 도출, AES-GCM 암호화 적용. 각 협상 라운드가 종단간 암호화. 참여자만 조건을 열람할 수 있습니다.

03

에이전트 위임

FunctionCall Access Key로 서버가 고용주를 대신하여 제한된 허용량 내에서 행동. 자동화된 온체인 트랜잭션과 제로 신뢰 타협.

04

무결성 검증

최종 합의의 SHA-256 해시를 NEAR에 저장. 쌍방 서명으로 상호 동의 보장. 양측을 위한 위변조 불가능한 정산 기록.
